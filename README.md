# SWYNEX Task 2 — Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the cleaned Titanic passenger dataset prepared during Task 1.

The objective is to analyze passenger data, understand patterns and relationships, identify trends, and present meaningful insights using statistical analysis and visualizations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
- Dataset: Titanic Passenger Dataset
- Records analyzed: 778
- Total columns: 15
- Missing values: 0
- Duplicate rows: 0

## Analysis Performed
1. Dataset overview and structure
2. Numerical and categorical statistical summaries
3. Overall survival analysis
4. Gender-wise survival analysis
5. Passenger class vs survival
6. Age distribution and age-group survival
7. Fare distribution and outlier detection
8. Family size vs survival
9. Embarkation port vs survival
10. Correlation analysis

## Key Findings
1. Overall passenger survival rate was 41.52%.
2. Female passengers had a survival rate of 74.06%, compared with 21.86% for male passengers.
3. First-class passengers had the highest survival rate at 63.68%.
4. Third-class passengers had the lowest survival rate at 25.94%.
5. Children had a survival rate of 57.35%.
6. Passengers travelling in families of 2–4 members generally showed higher survival rates than solo travellers.

## Visualizations
The project includes charts for:
- Overall survival count

- Passenger class vs survival

- Fare distribution

## Project Files
- `SWYNEX_Titanic_EDA.ipynb` — Complete EDA notebook

- `eda_charts.zip` — EDA visualization files

## Conclusion
The analysis reveals useful patterns between passenger survival and factors such as gender, passenger class, age, and family size. These findings help demonstrate how exploratory data analysis can uncover meaningful information from real-world datasets.

**Note:** These findings describe associations in the dataset and do not establish causation.
